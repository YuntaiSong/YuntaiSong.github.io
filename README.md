# Yuntai Song — Academic Personal Website

This repository contains the source code for the academic personal website of **Yuntai Song**, built with [Jekyll](https://jekyllrb.com/) using the [al-folio](https://github.com/alshedivat/al-folio) theme and hosted via **GitHub Pages**.

---

## 🚀 Quick Deployment Guide

To deploy this website under your own GitHub account (`https://YuntaiSong.github.io`):

### 1. Create a Repository on GitHub
1. Log in to [GitHub](https://github.com/).
2. Create a new public repository named **`YuntaiSong.github.io`** (replace with your exact GitHub username in lowercase if needed, e.g., `yuntaisong.github.io`).
3. Leave it empty (do NOT initialize with a README or license).

### 2. Connect and Push Local Code
In your local terminal inside this directory, run:
```bash
# Check your current branch (it should be main)
git branch -M main

# Set remote origin to your new repository
git remote set-url origin git@github.com:YuntaiSong/YuntaiSong.github.io.git
# (Or using HTTPS: git remote set-url origin https://github.com/YuntaiSong/YuntaiSong.github.io.git)

# Commit changes and push
git add .
git commit -m "feat: customize academic website for Yuntai Song"
git push -u origin main
```

### 3. Enable GitHub Pages Deployment
1. Go to your repository on GitHub: `https://github.com/YuntaiSong/YuntaiSong.github.io`
2. Click **Settings** ➔ **Pages** (under "Code and automation" in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select **Deploy from a branch**.
   - **Branch**: Select **`gh-pages`** branch (this branch is automatically generated by GitHub Actions after your first push) and folder **`/(root)`**.
   - Click **Save**.
4. That's it! In 2–3 minutes, your site will be live at:
   👉 **`https://yuntaisong.github.io/`**

> [!NOTE]
> Each time you push changes to the `main` branch, the GitHub Action in `.github/workflows/deploy.yml` will automatically build the site and deploy the updated files to the `gh-pages` branch.

## 📁 Content Management Guide

### 1. Biography & Home Page (`_pages/about.md`)
- Edit `_pages/about.md` to update your introduction, research interests, and education.
- To replace the profile picture, save your photo as **`assets/img/prof_pic.jpg`**.
- Contact details on the right sidebar can be adjusted under `more_info:` in `_pages/about.md`.

### 2. Publications (`_bibliography/papers.bib`)
- Publications are automatically parsed from BibTeX entries in `_bibliography/papers.bib`.
- Any publication marked with `selected={true}` will automatically show up under **Selected Publications** on your home page!
- Key BibTeX attributes supported:
  - `abbr={Conference/Journal}`: Generates a colored venue badge.
  - `bibtex_show={true}`: Displays a button to copy/view the BibTeX entry.
  - `abstract={...}`: Expands an abstract preview on click.
  - `arxiv={2401.xxxxx}`: Links directly to the arXiv page.
  - `pdf={https://...}`: Direct link to PDF.
  - `code={https://github.com/...}`: Adds a Code button.
  - `website={https://...}`: Links to a project page or demo.

### 3. News & Announcements (`_news/`)
- Add a new markdown file in `_news/` (e.g., `_news/2026-10-01-new-paper.md`).
- Frontmatter format:
  ```markdown
  ---
  layout: post
  date: 2026-10-01 10:00:00-0400
  inline: true
  related_posts: false
  ---
  Your announcement text here (markdown and HTML links supported).
  ```

### 4. Research & Projects (`_projects/`)
- Add new markdown files in `_projects/` (e.g., `_projects/3_my_project.md`).
- Specify `category: research` or `category: software` to group them into the respective sections.
- Attach screenshots or banners via `img: assets/img/your_project_image.jpg`.

### 5. Curriculum Vitae (`_data/cv.yml` & `_pages/cv.md`)
- Modify `_data/cv.yml` to update your education, experience, honors, and skills.
- To provide a downloadable PDF version of your CV, place your PDF in `assets/pdf/` and update `cv_pdf: /assets/pdf/your_cv.pdf` in `_pages/cv.md`.

### 6. Social Media & Contact Links (`_data/socials.yml`)
- Open `_data/socials.yml` to set your:
  - Google Scholar ID (`scholar_userid`)
  - ORCID (`orcid_id`)
  - LinkedIn (`linkedin_username`)
  - X / Twitter (`x_username`)
  - Email (`email`)

### 7. Global Configuration (`_config.yml`)
- Change site metadata, keywords, Google Analytics, or theme settings in `_config.yml`.
- If you use a custom domain (e.g. `yuntaisong.com`), update `url: https://yuntaisong.com` and add your domain to a `CNAME` file.

## 🛠️ Local Development (Optional)

If you have Docker installed on your computer, you can preview the website locally before pushing:
```bash
docker compose pull
docker compose up
```
Then visit `http://localhost:8080` in your web browser. Any changes you make will live-reload automatically.
